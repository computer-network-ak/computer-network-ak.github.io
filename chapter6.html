LEARNING FRAMEWORKObjectives, sequence, and key distinction
LEARNING OBJECTIVE

How does an IP datagram cross one LAN hop, and how does a switched LAN learn where hosts are?

CONCEPT SEQUENCE

Resolve next-hop address → build an Ethernet frame → arbitrate for the medium → switch by learned source MAC entries → verify the frame CRC.

KEY DISTINCTION

IP identifies routed interfaces end to end; MAC addresses and frame headers are replaced for each local hop.

6.1 Link protocols deliver frames across one hop

A route is a sequence of links. Each link may use a different framing, addressing, access, and error-control method. A network adapter implements much of the link layer in hardware and firmware while its driver cooperates with the operating system.

FRAMING

Mark boundaries

Wrap a network-layer datagram with a header and usually a trailer.

LINK ACCESS

Coordinate senders

Decide who can transmit over a shared broadcast medium.

ERROR CONTROL

Detect or recover

Identify corrupted frames; some links also acknowledge and retransmit locally.

WHAT CHANGES AT A ROUTER?

The end-to-end IP addresses normally remain. The router removes the incoming frame, updates the IP header, then creates a new frame with addresses and format for the next link.

6.5 A switch learns a LAN from arriving frames

The switch records each frame’s source MAC and incoming port. It forwards a known destination to one port, filters a destination on the same port, and floods an unknown or broadcast destination to all other ports.

6.6 VLAN, MPLS, and VXLAN create logical links

VLAN

Partition a switched LAN

Access ports carry one VLAN; trunks use 802.1Q tags to carry many VLANs. Inter-VLAN traffic needs layer-3 routing.

MPLS

Forward by short labels

Ingress routers attach labels; label-switching routers swap them along engineered paths or VPNs.

VXLAN

Carry Ethernet over IP

Encapsulates layer-2 frames in UDP and uses a large segment identifier, extending tenant networks across a routed fabric.

These technologies build an abstraction of a link over another network. They improve segmentation and traffic engineering, but require control-plane coordination and careful MTU planning.

6.7 Data-center networks optimize many short, parallel paths

A leaf-spine fabric connects every leaf switch to every spine, giving predictable hop count and many equal-cost routes. Servers often use multiple network interfaces; load balancers and service gateways distribute requests across replicas.

Advanced analysis Local delivery, shared media, and network virtualization

The link layer combines local addressing, framing, shared-medium coordination, error detection, switching, overlays, and data-center topology. The complete behavior appears only when these mechanisms are connected.

Link-layer reliability is local and optional
FRAME · ADAPTER · HOP

A network adapter encapsulates an IP datagram in a frame, adds link addresses and error-checking bits, and controls access to the medium. Possible services include framing, medium access, error detection, error correction, and reliable delivery.

Reliable link delivery is valuable on high-error channels because a local retransmission is faster than end-to-end recovery. It remains insufficient as a complete guarantee: later hops or devices can still lose or corrupt data, so transport or application integrity remains necessary.

Parity, checksums, and CRCs have different detection strength
REDUNDANCY · POLYNOMIAL DIVISION

One parity bit detects any odd number of bit flips but misses even-count patterns. Two-dimensional parity can locate and correct one flipped bit. Internet checksums are inexpensive arithmetic summaries but weaker against structured errors.

A CRC interprets bits as a polynomial over GF(2), appends zero bits, divides by a generator polynomial, and transmits the remainder. The receiver divides the complete codeword; a nonzero remainder indicates corruption. A well-chosen generator detects all single-bit errors and broad classes of burst errors, making CRCs suitable for link frames.

Multiple-access protocols trade collisions, coordination, and delay
ALOHA · CSMA · TAKING TURNS

Channel-partitioning protocols allocate time, frequency, or codes and work predictably under heavy load but waste idle shares. Random access lets a node transmit opportunistically: slotted ALOHA aligns attempts; CSMA senses before sending; CSMA/CD aborts a detected wired collision and backs off.

Polling and token passing coordinate turns and can offer fairness, but introduce controller/token overhead and failure modes. DOCSIS combines scheduled upstream opportunities with a downstream broadcast channel. No one scheme is best across light load, high load, propagation delay, mobility, and energy constraints.

ARP, Ethernet, and switch learning form one local-delivery system
MAC · LEARNING · FLOODING

ARP maps a next-hop IPv4 address to a MAC address on the local broadcast domain. A request is broadcast because the sender does not know the target adapter; the reply is normally unicast. The sender frames the IP datagram for the next hop, which may be the destination host or default router.

A switch learns a source MAC-to-port mapping from arriving frames. It forwards a known unicast only to the learned port, filters a frame whose destination lies on the incoming port, and floods unknown unicast or broadcast traffic. Entries age so topology changes can be relearned.

VLAN, MPLS, and VXLAN virtualize different forwarding scopes
802.1Q · LABELS · OVERLAYS

A VLAN creates separate logical broadcast domains on shared switches. Access ports carry one VLAN; trunks carry several using an 802.1Q tag. Inter-VLAN traffic crosses a router or layer-3 switch.

MPLS pushes short labels and forwards by a label-switched path, supporting traffic engineering and VPN separation below ordinary IP route lookup. VXLAN encapsulates Ethernet frames in UDP/IP and uses a 24-bit network identifier, allowing layer-2 segments to span a routed underlay. The underlay supplies reachability; the overlay supplies tenant topology.

Leaf–spine fabrics create many short equal-cost paths
DATA CENTER · ECMP

Hosts attach to leaf switches; every leaf connects to every spine. Any two leaves therefore communicate through the same number of switching stages and several equal-cost paths. ECMP hashes flows across those paths, increasing aggregate capacity.

Oversubscription compares downstream host capacity with available uplink capacity. East–west application traffic, incast toward one receiver, elephant and mice flows, shallow buffers, and failure convergence shape performance. Modern fabrics often combine routed underlays, VXLAN overlays, centralized orchestration, and telemetry.

A web request activates every layer
END-TO-END TRACE
  1. DHCP supplies address, prefix, gateway, and DNS resolver.
  2. ARP or Neighbor Discovery resolves the gateway’s link address.
  3. DNS resolves the service name, possibly through a recursive hierarchy and CDN mapping.
  4. Routing moves IP packets toward the selected address; each hop replaces the link frame.
  5. TCP+TLS or QUIC establishes secure transport state.
  6. HTTP requests representations; caches and application servers respond.

At every router, IP addresses normally remain end-to-end while link-layer addresses change for the next hop.

Technical reference Link-layer and LAN mechanisms

The link layer moves a frame across one link. Its central problems are framing, local addressing, error detection, and sharing a common medium.

LINK SERVICES

One-hop delivery

A network adapter encapsulates a datagram in a frame, identifies local endpoints, controls access to a shared link, detects errors, and may retransmit locally. Link-layer behavior changes from hop to hop even while the IP datagram remains the network-layer unit carried end to end.

ERROR DETECTION

Add redundancy deliberately

Parity detects selected bit errors; two-dimensional parity can locate a single-bit error. Internet checksum adds words with one’s-complement arithmetic. CRC treats bits as a polynomial and appends a remainder so common error patterns produce a nonzero remainder at the receiver. Detection is probabilistic unless the code guarantees a class of errors.

MULTIPLE ACCESS

Share one broadcast channel

Channel partitioning allocates time, frequency, or code. Random access lets nodes contend and recover from collision. Taking-turns protocols poll or pass a token. Pure and slotted ALOHA are simple but collision-prone. CSMA listens before sending; collision detection fits wired Ethernet, while collision avoidance fits Wi-Fi where sensing while transmitting is difficult.

ETHERNET

Frames and MAC addresses

An Ethernet frame carries destination and source MAC addresses, a type field, payload, and CRC, with preamble used for synchronization. MAC addresses identify link interfaces. Modern switched full-duplex Ethernet avoids collisions on each point-to-point link. Ethernet provides best-effort frame delivery; higher layers decide whether loss must be repaired.

LOCAL DELIVERY

ARP and self-learning switches

1 · SUBNET TESTHost compares destination with its own prefix.
2 · NEXT HOPUse destination host locally or default router remotely.
3 · ARPResolve next-hop IPv4 address to a MAC address.
4 · FRAMESend Ethernet frame to that MAC.
5 · LEARNSwitch records source MAC and incoming port.

A switch forwards a known unicast only to the learned port, floods an unknown unicast, and filters a frame when destination and source are on the same port. Entries age out so topology changes can be relearned. A broadcast frame is flooded within its broadcast domain.

VLAN

Logical broadcast domains

A VLAN partitions one switched infrastructure into separate layer-2 broadcast domains. Access ports carry one VLAN; trunk links carry several and use an 802.1Q tag. Communication between VLANs requires layer-3 routing. VLANs improve organization and isolation but do not replace end-to-end security policy.

MPLS AND VXLAN

Build logical forwarding over other networks

MPLS pushes short labels and forwards through label-switched paths, supporting traffic engineering and VPNs. VXLAN encapsulates Ethernet in UDP/IP and identifies virtual networks with a larger segment identifier, allowing layer-2 overlays across a routed data-center underlay.

DATA CENTERS

Many equal-cost paths

Leaf-spine fabrics provide predictable hop count and abundant east-west capacity. Equal-cost multipath distributes flows across links. Overlay networks separate tenant addressing from physical topology. Large transfers and short latency-sensitive flows compete, so scheduling, congestion control, and telemetry matter.

ONE WEB REQUEST

All layers working together

A new host obtains configuration through DHCP, resolves the gateway MAC with ARP, resolves the server name through DNS, establishes transport and security, then sends HTTP. Switches forward frames locally; routers forward datagrams between subnets; transport handles end-to-end delivery; the application interprets the response. This trace explains why each layer has different addresses and scope.

ADAPTER IMPLEMENTATION

Where the link layer runs

Most link functions run in a network interface controller with hardware, firmware, and driver support. The adapter transfers frames to/from host memory, computes checks or offloads, filters addresses, and interrupts or polls the CPU. The operating system driver configures queues and exposes packets to the network stack.

CRC MECHANICS

Polynomial division over bits

Sender and receiver agree on generator bits G of degree r. The sender appends r zeros to data D, divides by G using XOR arithmetic, and replaces the zeros with remainder R. The transmitted bits are divisible by G. A nonzero receiver remainder signals detected corruption.

CHANNEL SHARING DETAILS

Efficiency and coordination

FamilyExamplesBehavior
PartitioningTDMA, FDMA, code divisionPredictable allocation; idle users can waste their share.
Random accessSlotted ALOHA, ALOHA, CSMAEfficient at low load; collisions/backoff dominate at high load.
Taking turnsPolling, token passingControlled access; controller/token overhead and failure concerns.

Slotted ALOHA permits transmission only at slot boundaries and has maximum long-run efficiency about 1/e under the standard model; pure ALOHA is lower because vulnerable time doubles. CSMA improves efficiency by sensing first, but propagation delay means distant nodes may still begin together.

DOCSIS

Scheduled upstream, broadcast downstream

In cable access, the headend broadcasts downstream over shared channels. Cable modems request upstream transmission opportunities; the headend allocates minislots. This combines channel partitioning, request contention, and centralized scheduling. Traffic classes and service flows support different performance targets.

ARP DETAILS

Resolve the next-hop IPv4 address

An ARP request broadcasts “who has this IP?” with sender addresses. The owner replies with its MAC address, usually unicast. Hosts cache mappings temporarily. ARP is used only for an on-link next hop, not every remote destination. Gratuitous ARP can announce a mapping or detect conflicts. ARP spoofing exploits the lack of built-in authentication.

ETHERNET AND SWITCHING

Forward, filter, flood

The preamble synchronizes reception; addresses identify local interfaces; EtherType identifies payload; CRC detects frame errors. A switch learns source MAC → incoming port. Known destination on another port is forwarded; known destination on same port is filtered; unknown or broadcast destination is flooded. Entries age so movement and topology changes are relearned.

LOOPS AND VLAN TRUNKS

Control the layer-2 domain

Redundant switch links can circulate broadcasts indefinitely because Ethernet frames have no TTL. A spanning-tree protocol selects a loop-free active topology while retaining backup links. VLAN access ports classify untagged endpoint traffic; trunk ports carry tags for multiple VLANs. Native/untagged rules must be configured consistently.

MPLS FORWARDING

Label stack and forwarding equivalence

An ingress router classifies a packet and pushes a label. Transit label-switching routers swap labels using local tables. An egress router pops the label and resumes IP forwarding. Stacked labels support hierarchy and VPNs. MPLS can steer traffic along paths that ordinary destination routing would not choose.

END-TO-END WEB TRACE

Headers and addresses at each stage

  1. DHCP uses UDP inside IP inside Ethernet to obtain host configuration.
  2. ARP discovers the default gateway MAC.
  3. DNS resolves the server name, possibly crossing several routed networks.
  4. Interior and interdomain routing have already populated router forwarding tables.
  5. The client establishes TCP/TLS or QUIC and sends HTTP.
  6. At every routed hop, the link frame addresses change; the IP destination normally remains the server.
  7. The response reverses the logical process, possibly over a different network path.
TWO DESTINATIONS AT ONCE

The IP destination remains the remote host. The frame destination is only the next-hop interface on the current link.

6.9 Concept check

Why does a switch learn from the source address?

The incoming port proves where the source is currently reachable. The destination may still be unknown, so the switch learns the source first and then forwards, filters, or floods according to the destination lookup.

Why does ARP resolve only an on-link next hop?

An Ethernet frame crosses one local link. For a remote IP destination, the host resolves the default router’s MAC address; each later router creates a new frame for its own next hop.

Why does a link-layer CRC not replace end-to-end integrity?

The CRC protects one frame on one hop. Corruption can occur after that check or on another link, so transport or application integrity must cover the wider end-to-end scope.

How do VLAN and VXLAN differ?

A VLAN separates broadcast domains within a switched layer-2 environment. VXLAN encapsulates Ethernet in UDP/IP so logical layer-2 segments can span a routed underlay.

What changes when an IP datagram crosses a router?

The incoming frame is removed, IP forwarding state selects the next hop, TTL or Hop Limit changes, and a new link-layer frame is created. The destination IP address normally remains unchanged unless a function such as NAT modifies it.
