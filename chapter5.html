LEARNING FRAMEWORKObjectives, sequence, and key distinction
LEARNING OBJECTIVE

How do routers create consistent forwarding state despite failures, scale, and policy?

CONCEPT SEQUENCE

Learn topology or neighbor distances → compute candidates → apply intra-domain metrics or inter-domain policy → install routes → reconverge after change.

KEY DISTINCTION

OSPF seeks paths inside one administration. BGP exchanges reachability and policy between autonomous systems; it is not global shortest path.

5.1 The control plane creates forwarding state

A routing system observes topology and policy, computes paths, and installs data-plane rules. In a per-router control plane, every router runs routing software and exchanges messages with peers. In software-defined networking, a logically centralized controller computes rules for programmable devices.

DISTRIBUTEDRouters participate

OSPF and BGP maintain local control state and exchange protocol messages.

LOGICALLY CENTRALIZEDController has a broad view

Controller applications implement policy and program flow tables through a southbound interface.

BELLMAN–FORD IDEA

Node x estimates the cost to destination y as the minimum, over each neighbor v, of cost(x,v) + Dv(y). Repeated neighbor exchanges eventually spread better estimates.

Routing can be static or dynamic, global or decentralized, and load-sensitive or load-insensitive. Convergence means all routers have settled on mutually consistent routes after a change.

5.4 OSPF computes routes inside one autonomous system

Open Shortest Path First is a link-state interior gateway protocol. Routers discover neighbors, assign or learn interface costs, flood sequenced link-state advertisements, build synchronized link-state databases within each area, and run shortest-path first. Deployments protect OSPF control exchanges with the authentication mechanism appropriate to the protocol version and environment.

AREAS

Limit flooding

Hierarchical areas reduce control traffic and database size. Area 0 forms the backbone.

METRICS

Choose link costs

Operators can base cost on bandwidth or policy. Equal-cost paths may share traffic.

RECOVERY

Recompute on change

A new advertisement triggers database synchronization and route recalculation.

POLICY BEFORE DISTANCE

An AS often prefers customer-learned routes over peer or provider routes, even when the AS-PATH is longer. BGP supports economic and administrative policy, not a globally shortest path.

Anycast lets several sites announce the same prefix. Routing then sends a user toward the site selected by current BGP paths, which is useful for DNS, CDNs, and globally replicated services.

Advanced analysis Convergence, routing policy, and network automation

Routing and management determine which forwarding state exists. These additions connect graph algorithms to OSPF, BGP policy, SDN control, diagnostics, and configuration systems.

Link-state and distance-vector exchange different knowledge
DIJKSTRA · BELLMAN–FORD

In link-state routing, each router floods link information so all routers in the area build a topology database and independently run Dijkstra’s algorithm. In distance-vector routing, a router knows costs reported by neighbors and applies the Bellman–Ford recurrence Dₓ(y)=minᵥ{c(x,v)+Dᵥ(y)}.

Link state has broader visibility and event flooding; distance vector distributes the computation through neighbor updates. DV can suffer routing loops and count-to-infinity after a cost increase. Split horizon, poisoned reverse, triggered updates, and hold-down behavior reduce some loops but do not replace careful convergence design.

OSPF scales an autonomous system with hierarchy
AREAS · LSAs · SPF

OSPF routers discover neighbors, form adjacencies, flood link-state advertisements, and compute shortest paths from the synchronized database for their area. Costs are administratively chosen and need not be simple physical distance.

Areas limit flooding and shortest-path computation. Area 0 forms the backbone; area border routers summarize or carry reachability between areas. Design must preserve backbone connectivity and avoid excessive summarization that hides necessary detail. Equal-cost paths can be installed together for multipath forwarding.

BGP is a path-vector policy protocol
AS_PATH · NEXT_HOP · LOCAL_PREF

BGP advertises reachable prefixes with attributes. AS_PATH records autonomous systems and rejects a route containing the receiver’s own AS, helping prevent loops. NEXT_HOP identifies where traffic should leave. LOCAL_PREF expresses policy inside one AS; MED can suggest an entry point to a neighbor; communities attach policy labels.

Selection typically applies local policy before path length. Export rules reflect business relationships: a network usually advertises customer routes broadly but does not provide free transit between two providers. IP anycast originates one prefix from several sites and lets routing policy direct each source toward a preferred instance.

SDN makes control logically centralized, not necessarily physically singular
APPLICATION · CONTROLLER · SOUTHBOUND

Network-control applications express goals such as routing, access policy, traffic engineering, or load balancing. A controller maintains a network-wide view and translates those goals into device rules. A southbound protocol such as OpenFlow carries flow modifications, statistics requests, port state, and packet-in events.

Controllers are replicated for availability and scale. The difficult problem is consistent state: devices and controller replicas may observe events at different times. Safe updates may require versioned rules and ordered installation so packets never traverse a partially programmed path.

ICMP explains IP failures but is not a separate transport
ERROR REPORTING · DIAGNOSTICS

ICMP messages are carried inside IP and report conditions such as destination unreachable, TTL expiration, parameter problems, and Packet Too Big. Echo Request/Reply supports ping. Traceroute provokes TTL expiration at successive hops, then recognizes a destination response.

An ICMP error includes part of the triggering packet so the source can associate it with a flow. ICMP may be filtered or rate-limited, so silence does not prove that the destination is down. ICMP errors describe forwarding outcomes; they do not repair the failed application transaction.

Monitoring and configuration use different data models
SNMP · MIB · NETCONF · YANG

SNMP represents managed variables in a Management Information Base. A manager can read values, sometimes set them, and receive asynchronous traps or informs. It is widely used for counters, status, and alerts.

NETCONF performs structured configuration operations and supports concepts such as candidate configuration, validation, commit, and rollback. YANG defines the schema, types, constraints, and hierarchy of configuration and operational data. Model-driven management reduces vendor-specific text parsing and enables automation to validate intended state before applying it.

Technical reference Control-plane mechanisms

Routing computes paths under scale, failure, and policy. Modern control planes combine distributed protocols, logically centralized controllers, and management systems.

ROUTING MODELS

Link state and distance vector

Link-state routers flood link information so each router builds the same graph and runs Dijkstra. Distance-vector routers exchange destination costs with neighbors and repeatedly apply the Bellman–Ford relation. Link state needs topology dissemination and computation; distance vector uses local messages but may converge slowly and suffer count-to-infinity after failures.

AUTONOMOUS SYSTEMS

Separate interior and interdomain routing

An autonomous system is a network under one administrative policy. Interior protocols optimize paths within an AS. Interdomain routing exchanges reachability and policy between ASes. Hierarchy limits state and allows each organization to control its own routing decisions.

OSPF

Link state inside an AS

OSPF discovers neighbors, measures link costs, floods link-state advertisements, and runs shortest-path computation. Areas reduce flooding and database size; area 0 forms the backbone. Equal-cost multipath can use several next hops. Authentication and sequence/age fields help protect and refresh state.

BGP

Policy-rich path-vector routing

BGP advertises prefixes with attributes. AS-PATH helps prevent loops and exposes the sequence of ASes. NEXT-HOP identifies where to send traffic. LOCAL_PREF expresses an operator’s preferred exit; MED suggests an entry to a neighboring AS. Selection is policy first, then tie-breaking—not simply globally shortest distance.

  • eBGP: exchanges routes between ASes.
  • iBGP: distributes external routes inside an AS.
  • Export policy: controls which neighbors learn a route.
  • Anycast: multiple sites advertise the same prefix.

“Logically centralized” does not require one physical server. Production controllers replicate state and partition work for availability and scale. A controller must handle stale information, concurrent changes, partial failure, and safe rule-update ordering.

ICMP

Report errors and diagnostics

ICMP is carried inside IP. Destination-unreachable, time-exceeded, echo request/reply, and packet-too-big messages help endpoints and operators. Traceroute elicits time-exceeded messages by sending probes with increasing TTL. ICMP reports network conditions; it does not make IP reliable.

MANAGEMENT

Observe, configure, automate

Management gathers counters, events, topology, and configuration. SNMP managers read or set MIB objects and receive traps/informs. Modern systems also use structured models such as YANG with NETCONF/RESTCONF or streaming telemetry. Monitoring must connect symptoms to service impact and preserve change history.

CONVERGENCE

Correct routes after change

Convergence includes detecting a failure, propagating new information, recomputing paths, and installing forwarding state. Faster is not always safer: aggressive timers can amplify transient failures. Loop-free updates and ordered rule installation reduce blackholes and temporary loops.

LINK-STATE ALGORITHM

Dijkstra step by step

  1. Initialize the settled set with the source and tentative distances through direct links.
  2. Select the unsettled node with smallest tentative distance.
  3. Add it to the settled set.
  4. Relax each outgoing edge: compare current distance with distance through the new node.
  5. Repeat until all reachable nodes are settled.

The predecessor relation forms a shortest-path tree. Equal-cost paths may produce several valid next hops. Negative link costs are unsuitable. Link-state flooding must suppress duplicates and age stale advertisements.

DISTANCE VECTOR

Distributed Bellman–Ford

Each router stores a cost estimate to every destination and receives vectors from neighbors. A local-link change or better received route triggers recomputation and advertisement. Good news often travels quickly; bad news may count upward through a loop. Split horizon and poison reverse prevent some two-node loops but not every topology. Triggered updates and hold-down behavior affect convergence.

OSPF OPERATION

Neighbor to forwarding table

Hello packets discover and maintain adjacency. Routers synchronize the database within an area and reliably flood newer advertisements. Each router computes paths from its area’s database and incorporates inter-area summaries. Hierarchical areas limit flooding; area border routers summarize or connect areas to backbone area 0. External routes enter through redistribution or AS boundary routers.

Typical commercial policy prefers customer-learned routes over peer and provider routes because customers pay for transit. An AS normally does not export a route learned from one provider or peer to another provider or peer, avoiding unpaid transit. Route aggregation and filtering improve scale and safety.

BGP SELECTION SIGNALS

Attributes serve different scopes

LOCAL_PREF is internal and expresses operator preference. AS-PATH records traversed ASes and prevents an AS from accepting a route containing itself. ORIGIN and MED help tie-breaking and inbound suggestions. NEXT_HOP must be reachable through the interior routing system. Hot-potato routing often chooses the closest exit after higher policy choices tie.

SDN EVENT TRACE

React to topology change

A switch reports link status or telemetry. The controller updates its network graph, recomputes policy-compliant paths, and determines rule changes. A consistent update may install downstream rules first, tag new traffic with a version, then remove old rules only after old traffic drains. Replicated controller instances must agree on ownership and state.

OPENFLOW CONTROL

Messages between controller and switch

The controller can add, modify, or delete flow entries and query counters. A switch can send packet-in events when no rule matches, port-status changes, and error messages. Packet-out directs a particular packet. Reactive installation handles new flows but adds first-packet latency; proactive installation avoids that cost for predictable policy.

ICMP DETAILS

Messages that help IP operate

Echo request/reply supports ping. Time exceeded reports TTL expiration or fragment reassembly timeout. Destination unreachable distinguishes network, host, port, or administrative failures. Packet Too Big is essential to IPv6 path MTU discovery. ICMP quotes part of the triggering packet so the endpoint can identify the affected flow.

5.9 Concept check

Link state versus distance vector?

Link state distributes topology and computes locally; distance vector exchanges destination costs and converges iteratively through neighbors.

Why split OSPF and BGP?

OSPF optimizes routing inside one administration. BGP scales policy exchange across independently operated networks.

How does traceroute find routers?

It sends probes with increasing TTL. Each router that expires a probe returns ICMP Time Exceeded.

Is an SDN controller one machine?

Usually no. It is logically centralized but commonly replicated and distributed for availability and scale.
