LEARNING FRAMEWORKObjectives, sequence, and key distinction
LEARNING OBJECTIVE

How do changing radio conditions and movement alter link access, scheduling, and reachability?

CONCEPT SEQUENCE

Discover and authenticate → contend or receive scheduled resources → adapt coding/rate → hand over attachment → update the forwarding path.

KEY DISTINCTION

Wireless loss, mobility, and congestion can look similar to transport. Diagnose the radio link, access scheduler, and end-to-end path separately.

7.1 Wireless adds a changing, shared channel

Definition. Wireless networking transmits information using electromagnetic waves rather than a guided cable between each communicating pair. Mobility means a device changes its point of attachment or location while requiring service.

How it works. Receivers cope with noise, interference, attenuation, and multipath. Shared access and changing signal quality affect delivery; mobility adds discovery, handover, and reachability decisions.

Example. A stationary laptop on Wi-Fi is wireless but not moving. A device that moves between attachment points has mobility concerns in addition to radio transmission concerns.

A wireless host communicates through a base station or access point, or directly in an ad hoc link. A network may be infrastructure-based or infrastructureless, single-hop or multi-hop. Mobility adds a separate challenge: preserving reachability while a device changes its attachment point.

INTERFERENCE

Signals overlap

Other transmitters and noise reduce the receiver’s ability to distinguish symbols.

HIDDEN TERMINAL

Senders cannot hear each other

Two stations may both reach an access point while being outside each other’s sensing range.

FADING

The channel changes

Path loss, shadowing, multipath, and movement vary signal strength and error rate.

7.2 Coding and modulation trade rate for robustness

Definition. Modulation maps information to signal variations. Channel coding adds structured redundancy for error recovery. A modulation and coding scheme selects a combination suited to channel conditions.

How it works. More distinguishable symbols can carry more bits per symbol but need better signal quality. Added redundancy consumes capacity while improving recovery under suitable error conditions.

Example. When a device moves farther from an access point, it may switch to a lower-rate, more robust scheme to maintain communication rather than keep a fast but unreliable one.

Bits are protected by channel coding, mapped to symbols, and modulated onto a waveform. Higher-order modulation carries more bits per symbol but needs a cleaner channel. Adaptive systems choose a modulation and coding scheme from measured channel quality.

7.3 Wi-Fi uses collision avoidance and link-layer recovery

Definition. Wi-Fi is wireless LAN networking based on IEEE 802.11. An access point connects associated stations to a distribution system; association is not the same as obtaining IP configuration or Internet access.

How it works. Stations discover a network, perform the required access/security exchanges, and contend or follow applicable scheduling rules for airtime. Local acknowledgments and retries assist frame delivery.

Example. A phone may associate successfully with an access point but still fail to obtain a DHCP lease. Radio association and network-layer configuration are distinct stages.

An 802.11 station discovers networks from beacons or probes, authenticates, associates with an access point, and then exchanges frames through it. A basic service set joins stations to one AP; a distribution system can connect many APs into an extended network.

7.4 The 5G radio access network schedules shared spectrum

Definition. A radio access network (RAN) connects user devices to a mobile operator’s core through base stations. In 5G, the gNodeB is the base-station role and UE means user equipment.

How it works. The base station schedules shared radio resources using channel feedback and service requirements. Coding, modulation, and retransmission adapt delivery to radio conditions.

Example. Two phones near the same base station may obtain different rates because their signal conditions, demand, and scheduling allocations differ.

A user equipment device connects to a gNodeB. The base station chooses time-frequency resources, modulation, coding, power, and retransmission for active users. Scheduling balances channel quality, latency targets, fairness, and service class.

7.5 The 5G core separates control and user traffic

Definition. The mobile core manages subscriber connectivity and carries user traffic between the radio network and external data networks. Control-plane functions manage sessions and mobility; user-plane functions forward traffic.

How it works. Authentication and session procedures authorize connectivity and create forwarding state. Separating control from user traffic allows these responsibilities to scale and be placed differently.

Example. A phone’s application data can pass through a user-plane function while separate signaling manages its session. The signaling is not the application payload.

A service-based architecture exposes control functions through APIs. Network slicing can create logical networks with different policies and resource treatment over shared infrastructure.

7.6 Mobility separates identity from current location

Definition. Mobility management maintains reachability as a device changes attachment points. Handover transfers an active connection or service context to another access point or base station.

How it works. The system updates radio or forwarding state and may use anchors or tunnels to preserve continuity. Whether an IP address changes depends on the network design and boundary crossed.

Example. Walking between coverage areas during a call may trigger a handover. Switching to an unrelated Wi-Fi network can also change the IP path and disrupt sessions.

7.7 Wireless designs specialize for range, energy, and topology

Definition. Wireless technologies choose different tradeoffs among range, power use, rate, cost, and topology. A short-range peripheral link and a long-lived remote sensor do not have the same requirements.

How it works. Designers choose spectrum, duty cycle, channel access, and protocol overhead for the workload. Sleeping saves energy but can increase the time before a device can receive data.

Example. A battery sensor sending a small reading every hour may favor low energy use over video-rate throughput; a headset instead needs timely continuous audio.

Essential details Details that matter

Check the short answer, then the scope and exceptions. These distinctions prevent common mistakes in exams, interviews, and troubleshooting.

01Are wireless networking and mobility the same?

No. A stationary wireless camera uses radio without moving; a laptop can move between wired networks. Wireless describes the medium, while mobility describes a changing attachment point or location. Link association, IP addressing, and application-session continuity are separate states. Good signal strength does not prove that a device has working DNS or Internet access.

Link to this answer
02What are SSID, BSSID, and an access point?

SSID is the network name visible to users; multiple access points may advertise the same name. A BSSID identifies a basic service set, commonly with a MAC-address-like identifier for an AP radio’s service. An AP can advertise multiple networks. A shared SSID is not proof that two radios are equally trusted, nor does it guarantee seamless roaming.

Link to this answer
03Does a Wi-Fi ACK mean the web server received the request?

No. A Wi-Fi acknowledgment confirms a local link transmission under that protocol’s rules. IP forwarding, transport delivery, and application processing are later stages. A local retransmission may repair radio loss before TCP notices; excessive retries can instead increase RTT and jitter. Broadcast and multicast delivery do not generally use the same individual ACK behavior as ordinary unicast.

Link to this answer
04How do hidden and exposed terminals differ?

Hidden senders cannot hear one another but can interfere at a common receiver. An exposed sender hears nearby traffic and may defer even when its own transmission could have been safe at another receiver. Carrier sensing alone cannot infer every receiver’s interference conditions. RTS/CTS can reduce hidden-terminal problems but adds overhead and does not eliminate every collision.

Link to this answer
05Why is Wi-Fi file-transfer speed lower than its displayed link rate?

The displayed rate describes a selected physical mode, not exclusive application capacity. Headers, interframe spaces, contention, acknowledgments, retries, and other stations consume airtime. A slow or distant client may occupy substantial airtime even while transferring little data. Wider channels or more antennas do not help if the client, signal conditions, backhaul, or server is the bottleneck.

Link to this answer
06Is 5 GHz Wi-Fi the same as 5G cellular?

No. 5 GHz is a radio-frequency band used by some Wi-Fi networks. 5G identifies a cellular generation, which can operate in several frequency ranges. Wi-Fi generation names, channel widths, bands, and cellular generations describe different things. Equipment must support the particular band and mode, and local spectrum rules determine what channels may be used.

Link to this answer
07Does changing access points always change my IP address?

No. Roaming within the same bridged subnet may preserve the address. Moving to another IP subnet can require new addressing unless a mobility mechanism maintains reachability. Cellular networks use session and forwarding state to manage movement. A preserved IP address still does not guarantee uninterrupted application service: authentication, handover delay, packet loss, and timeout settings also matter.

Link to this answer
08Is a SIM identity the same as an IP address?

No. Subscriber credentials identify and authenticate a subscription; a packet-data session supplies network connectivity and may assign addresses. Radio identifiers, subscriber identity, phone numbers, and IP addresses have different scopes and lifetimes. In the 5G core, access/mobility management, session management, and user-plane forwarding are separate responsibilities rather than one device doing every task.

Sizes, headers & limits Wireless layers: airtime, addresses, and acknowledgments

Understand the reason behind each number. Header sizes belong to specific protocols; worked examples state the assumptions needed to use them.

Why Wi-Fi needs more than Ethernet’s two MAC addresses

A wireless hop may involve a station, an access point, and a different original source or final destination in the distribution system. A basic three-address 802.11 data header is 24 bytes: Frame Control 2, Duration/ID 2, three addresses of 6 each, and Sequence Control 2. Four-address, QoS, and other variants add fields; control frames can be shorter. There is no single header size for every Wi-Fi frame.

Why Wi-Fi uses collision avoidance

A radio’s own transmission can overwhelm a weak incoming signal, so collision detection while transmitting is not like shared wired Ethernet. Stations sense the medium and contend with backoff; many unicast frames use link acknowledgments and retries. Hidden stations can collide at a receiver even when each hears an idle channel. RTS/CTS can reserve airtime in suitable cases but adds overhead and does not eliminate all interference.

Why the advertised Wi-Fi rate is not download speed

The PHY rate describes a selected signaling mode, not useful application throughput. Preambles, MAC headers, security overhead, interframe spacing, contention, acknowledgments, and retries consume airtime. Channel width, modulation/coding, spatial streams, and signal conditions affect the rate. Aggregation amortizes overhead; slow or repeatedly retried transmissions occupy airtime that others cannot use simultaneously.

Why a Wi-Fi ACK is not a TCP ACK

A Wi-Fi acknowledgment confirms a local wireless reception under that link protocol; a TCP ACK concerns end-to-end byte receipt. Local retries can hide some radio loss from TCP, while also increasing delay. Neither acknowledgment establishes that a server committed an application transaction. Roaming between access points and changing an IP subnet are also different events.

A payload-only airtime lower bound

Sending 1500 bytes at a constant 54 Mb/s takes 1500 × 8 / 54,000,000 ≈ 222 μs for those bits alone. Real airtime is longer because PHY framing, MAC overhead, contention, and feedback must be included. Do not compute a reliable download rate by treating 54 Mb/s as pure application data.

Advanced analysis Radio behavior, mobility, and cellular operation

Wireless networking joins radio physics, shared-medium scheduling, attachment, core-network state, and mobility. These mechanisms explain why wireless performance changes even when the Internet path is unchanged.

Radio quality is a time-varying signal-to-noise problem
PATH LOSS · FADING · INTERFERENCE

Received power falls with distance and obstacles. Multipath copies arrive with different delay and phase, causing constructive or destructive interference. Movement changes the channel within a coherence time. Other transmitters add interference, while electronic and thermal sources add noise.

Higher-order modulation carries more bits per symbol but requires better signal quality. Coding adds redundancy so some errors can be corrected. Adaptive modulation and coding selects a robust low rate under poor conditions and a denser high rate when SNR is strong. MIMO can provide spatial diversity, spatial multiplexing, or beamforming gain.

Wi-Fi uses collision avoidance because collision detection is impractical
CSMA/CA · BACKOFF · ACK

A station senses the channel, waits an interframe interval, chooses a random backoff, pauses the countdown while the channel is busy, and transmits when it reaches zero. The receiver sends a link-layer ACK; lack of ACK triggers another attempt with a larger contention window.

A radio cannot reliably detect a weak incoming signal while transmitting its own strong signal. Hidden terminals may each hear the access point but not one another. Optional RTS/CTS reserves the channel using a duration field and is worthwhile mainly when avoiding a long collision saves more than the control-frame overhead.

Discovery and association create local wireless state
BEACON · SCAN · AUTHENTICATE

Access points periodically advertise network identity and capabilities in beacons. A client can passively listen or actively send probe requests. It selects an AP, authenticates according to the security mode, associates, and then obtains network-layer configuration.

Association is a link-layer relationship, not proof of Internet reachability. Roaming to another AP changes link state and may require reauthentication, key installation, and switch updates while retaining the same IP subnet—or may also trigger an IP-layer move.

5G schedules a time–frequency grid rather than contending like Wi-Fi
OFDM · RESOURCE BLOCK · MIMO

OFDM divides a channel into orthogonal subcarriers. The scheduler allocates time-frequency resource elements/blocks to devices based on channel reports, demand, quality of service, and fairness. OFDMA allows different users to occupy different subsets simultaneously.

The RAN protocol stack separates radio resource control, service-data mapping, packet convergence, reliable radio-link behavior, medium access, and physical transmission. A scheduler may maximize instantaneous throughput, equalize long-run service, or use proportional fairness to balance both. Beamforming and MIMO add spatial scheduling dimensions.

The 5G core separates mobility control from user forwarding
AMF · SMF · UPF

The Access and Mobility Management Function handles registration, reachability, and mobility signaling. The Session Management Function controls packet-data sessions and selects/configures user-plane functions. The UPF forwards user traffic between the RAN and data networks and applies rules such as tunneling and policy enforcement.

Subscriber identity and credentials enable authentication through the home network, including roaming scenarios. User traffic is tunneled so mobility can change the radio attachment while preserving the logical data session. Control functions use service-based APIs, allowing software deployment and scaling.

Handover moves state before the old path disappears
MEASURE · PREPARE · SWITCH

A device or network measures neighboring cells. The source side prepares a target, transfers context, directs the device to switch, updates the user-plane path, and releases old resources. During transition, packets may be forwarded from the old base station, buffered, reordered, or briefly duplicated.

Handover decisions consider signal quality, load, policy, speed, and service continuity. Mobility is therefore more than discovering a new link: authentication, tunnel endpoints, forwarding rules, radio scheduling, and transport behavior must all adapt.

Bluetooth, satellite, and IoT optimize for different constraints
RANGE · ENERGY · TOPOLOGY

Bluetooth uses short-range radios and frequency hopping to reduce persistent interference. Low-energy modes coordinate advertising, connection intervals, and sleep. Satellite systems trade broad coverage for propagation delay, moving footprints, gateway placement, and handoff; LEO constellations reduce delay relative to geostationary orbit.

IoT links may prioritize multi-year battery life, low device cost, small messages, or long range rather than throughput. Duty cycling, compact frames, scheduled wake periods, mesh forwarding, and gateway translation are common. The correct wireless design follows the workload and energy budget.

Wireless links share spectrum, experience time-varying propagation, and support moving endpoints. Scheduling and mobility therefore become central design problems.

WIRELESS CHANNEL

Attenuation, interference, multipath

Received power falls with distance and obstacles. Other transmitters raise interference. Reflections create multiple delayed copies that may reinforce or cancel. Signal-to-noise-plus-interference ratio influences the modulation and coding rate that can be decoded. A rate chosen for a strong channel may fail when fading changes it.

CODING AND MODULATION

Trade efficiency for robustness

Modulation maps bits onto signal symbols. Higher-order modulation carries more bits per symbol but needs a cleaner channel. Error-correcting codes add redundancy. Adaptive modulation and coding chooses a mode from channel measurements. MIMO uses multiple antennas for diversity, beamforming, or parallel spatial streams.

5G RADIO ACCESS

Base station schedules resources

A 5G base station divides time-frequency resources among devices, choosing modulation, coding, retransmission, and antenna strategy from channel and service information. Unlike Wi-Fi contention, scheduled access gives the infrastructure explicit control. Network slicing and quality mechanisms can map different service needs onto shared infrastructure.

5G CORE

Separate control and user planes

Control functions authenticate devices, manage registration and mobility, and create sessions. The user-plane function forwards application packets toward data networks. Software-based functions can be placed and scaled flexibly. A device may keep identity and session state while radio attachment changes.

MOBILITY

Identity, location, and handover

Mobility management must locate a device, preserve reachability, and move forwarding state. In Wi-Fi, a station reassociates with another access point and switches relearn its location. Cellular handover coordinates old and new radio nodes and updates tunnels or forwarding anchors. Route optimization reduces detours but increases coordination.

ENERGY

Sleeping radios need schedules

Radios consume energy while transmitting, receiving, and often while merely listening. Wi-Fi power save and cellular discontinuous reception let devices sleep while infrastructure buffers data and advertises wake times. Longer sleep saves energy but adds latency.

OTHER WIRELESS SYSTEMS

Different range and power targets

Bluetooth supports short-range personal networks and low-energy operation. Low-power IoT systems trade throughput for long battery life and simple radios. Satellite networks cover wide areas but introduce propagation delay and changing topology, especially in low-Earth-orbit constellations.

CHANNEL QUALITY

From signal power to data rate

Path loss reduces received power with distance. Shadowing adds slower variation from obstacles; multipath creates rapid frequency- and time-selective fading. Noise and interference reduce SINR. A receiver estimates channel quality and feeds it into rate selection. Coding adds redundancy; interleaving spreads burst errors; OFDM divides a wideband channel into narrow subcarriers; MIMO exploits multiple antennas.

WI-FI CSMA/CA

Interframe spaces and backoff

A station senses the channel. After it remains idle for the required interval, the station counts down a random backoff only while idle. It transmits when the counter reaches zero. The receiver returns a link ACK after a shorter interval, giving the ACK priority. Missing ACK triggers a larger contention window and retry. Physical and virtual carrier sensing both influence deferral.

802.11 FRAME

Why Wi-Fi may need four addresses

A Wi-Fi data frame includes frame-control flags, duration, several address fields, sequence control, payload, and frame check sequence. Address interpretation depends on whether the frame travels to or from the distribution system. The fields can identify transmitter, receiver, source, destination, and bridging access point. Sequence numbers help discard duplicate retransmissions.

DISCOVERY AND ROAMING

Attach to a wireless network

Wi-Fi clients passively hear beacons or actively send probes, choose an access point, authenticate, and associate. Enterprise networks may perform 802.1X/EAP authentication. Roaming requires reassociation and forwarding-state updates. A cellular device searches synchronization signals, selects a cell, performs random access, authenticates with the core, and establishes radio bearers and a data session.

5G RAN SCHEDULING

Allocate time, frequency, coding, and antennas

The base station schedules resource blocks using buffer demand, channel quality, retransmission state, quality class, fairness, and device capability. Proportional-fair scheduling balances instantaneous channel opportunity against a user’s historical service. Hybrid ARQ combines error correction with rapid retransmission. Beam management selects useful transmit/receive directions.

A scheduler can maximize throughput by favoring strong channels, but strict throughput optimization may starve edge users. Delay-sensitive traffic needs deadlines or priority; large transfers value sustained rate; control traffic needs reliability.

5G CORE FUNCTIONS

Registration and session state

The access and mobility function handles signaling and mobility. Session management establishes packet-data sessions and chooses user-plane functions. Authentication functions verify subscriber credentials. Policy and subscriber data functions supply authorization and service rules. The user-plane function anchors and forwards traffic, keeping bulk data separate from control signaling.

MOBILITY MODES

What changes during movement

At layer 2, a Wi-Fi client may retain its IP while moving within one subnet. At layer 3, changing subnets usually changes the care-of address. Cellular networks maintain session continuity using tunnels and mobility anchors while radio attachment changes. Internet mobility can use indirection, rendezvous, identifier/locator separation, multipath transport, or application reconnection.

WAKE AND SLEEP

Coordinate energy saving

A sleeping receiver cannot continuously hear incoming data, so infrastructure buffers packets and signals delivery opportunities. Wi-Fi clients use beacon timing and traffic indication maps. Cellular discontinuous reception defines monitoring cycles. Deeper/longer sleep saves energy but increases paging or downlink latency and may require more synchronization work.

7.8 Concept check

Why does Wi-Fi avoid rather than detect collisions?

A transmitting radio overwhelms its own receiver, and hidden terminals may not hear one another. ACKs and random backoff reveal and recover from failure.

What does a 5G scheduler decide?

Which users receive time-frequency resources, with what modulation, coding, power, and retransmission treatment.

What changes during handover?

The access attachment and forwarding path change while identity, security context, and preferably the application session continue.

Why adapt modulation?

Dense modulation raises rate on a clean channel; simpler modulation remains reliable when SINR is low.
